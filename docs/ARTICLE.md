# DETACHED HEAD — углы для сторителлинга

Если игра выстрелит, вот готовые рамки для write-up (dev.to / HN / vox-style).
Каждая — отдельный хук, не «порт DOOM №2».

## Заголовки-кандидаты

1. **«I designed a game engine that compiles to GitHub markdown»** — главный
   угол: DoomMe *портировал* существующую игру в ограничения среды; DETACHED
   HEAD спроектирован под них с нуля. Дизайн уровня подбирался под бюджет
   узлов — размер уровня = размер репозитория, это гейм-дизайн и инженерия
   одновременно.
2. **«Speedrunning a GitHub README»** — лидерборд через Issues: маршрут как
   строка токенов, CI-валидатор, таблица результатов. У DoomMe нет и не может
   быть сообщества игроков — у нас есть.
3. **«The boss has HP because its state lives only inside the arena»** —
   технический угол про математику состояний: почему в «DOOM в README»
   стрельба — self-loop, и как конечный подграф арены даёт настоящую
   механику без комбинаторного взрыва.

## Ключевые факты для статьи

- 4233 markdown-файла, ~4230 кадров, ноль строк JS на «клиенте»; движок —
  связность ссылок.
- Рендерер — ~100% numpy Wolfenstein-рейкастер, вся графика процедурная
  (текстуры, спрайты, HUD, баннеры). Ни одного стороннего ассета — ноль
  юридической серости (в отличие от WAD-зависимых проектов).
- Стены = отсутствующие ссылки; замок гейта и ключ LGTM — два «настоящих»
  игровых механима, возможных потому, что состояние квантуется в граф.
- Монолит «регенерирует», если сбежать из арены — не баг, а прямое следствие
  stateless-формата: HP существует только в узлах арены.
- Клик = переход по ссылке: играется на любом тарифе, в любом браузере,
  без JS — GitHub и есть рантайм.

## Демо-примеры для треда/поста

- GIF: спавн → коридор main → feature → ключ → гейт открылся → арена →
  4 выстрела → DEPLOYED.
- Скрин пары `game/*.md` рядом с `_preview/*.html` — «одно и то же
  состояние, два рантайма: GitHub и файловая система».
- Issue `/run FFRR...` → коммит бота в LEADERBOARD.md → скрин таблицы.

## Чего НЕ делать в статье

- Не называть это «Doom в README» — игра оригинальная, сравнение уместно
  только как «стимул и ограничение».
- Не продавать как движок для всех игр: формат тянет пошаговые/квантованные
  механики; всё живое/real-time — за пределами математики состояний.
