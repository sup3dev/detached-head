# DETACHED HEAD — дизайн-документ

Игра-шутер, **целиком скомпилированная в граф markdown-файлов**. Никакого
кода не исполняется на GitHub: каждый узел игры — это `.md` со скриншотом и
таблицей эмодзи-ссылок. Клик по ссылке = переход на другой узел. «Движок» —
это связность ссылок.

Это оригинальный IP (движок, текстуры, уровень — сгенерированы кодом этого
репозитория), никаких сторонних ассетов.

## Сюжет

Ты разработчик. Ты уснул во время деплоя и очнулся **внутри собственного
репозитория**. Выход один: найти approval (🔑 LGTM), открыть мерж-гейт
`release` и убить **LEGACY MONOLITH** в проде. Баги по веткам — замороженные
артефакты давно минувших спринтов; твоё оружие (`git blame`) работает только
в коде прода.

## Математика состояний (почему всё именно так)

Формат «игра в README» = stateless-граф: один узел = один квантованный
состояние игры = один `.md` + одна картинка. Любой бит состояния умножает
число узлов, поэтому:

| Состояние | Квантование | Стоимость |
|---|---|---|
| позиция | клетки сетки (~430 проходимых) | база |
| ракурс | 4 стороны света (N/E/S/W) | ×4 |
| ключ LGTM | есть/нет | ×2 (только HUD + гейт) |
| HP босса | 4..0 | **только внутри арены** — см. ниже |

**Ключевой трюк — арена с живым боссом.** У DoomMe стрельба — self-loop,
потому что HP монстров умножало бы ВЕСЬ граф. Здесь HP босса существует
только в узлах арены: `(клетка арены, угол, hp)`. Выйдешь из арены и
вернёшься — монолит «регенерирует» (hp=4). Это честно описано в лоре:
*«легаси-монолит восстанавливается, если отступить»*.

**Стены = отсутствующие ссылки.** Переход в стену — нет ссылки (эмодзи без
href). Заблокированный гейт без ключа — тоже.

## Узлы и переходы

Состояние обычной зоны: `(cell, angle, key)`, `key ∈ {0,1}`.
Состояние арены: `(cell, angle, hp)`, `hp ∈ {4,3,2,1}` (0 = победа, узел
`WIN`).

Действия игрока (один клик = одно действие):

| Токен | Эмодзи | Действие |
|---|---|---|
| `F` | ⬆️ | шаг вперёд по направлению взгляда |
| `B` | ⬇️ | шаг назад |
| `L` | ⬅️ | поворот налево на 90° |
| `R` | ➡️ | поворот направо на 90° |
| `X` | 💥 | выстрел (осмысленен только в арене) |

Спец-переходы:
- вход в клетку ключа → `key=1` автоматически (ключ подбирается);
- гейт проходим ⇔ `key=1`; в рендере гейт физически меняется (закрыт/открыт);
- вход в арену из коридора гейта → состояние с `hp=4`;
- `X` при `hp>1` → то же клетка/угол, `hp-1`; `X` при `hp==1` → узел `WIN`;
- `X` вне арены → self-loop (холостой выстрел);
- выход из арены назад → обычная зона с `key=1`; повторный вход → снова `hp=4`.

## Схема `data/graph.json` (контракт для валидатора спидрана)

```jsonc
{
  "meta": {
    "name": "DETACHED HEAD",
    "level": "repo-01",
    "moves": ["F", "B", "L", "R", "X"]  // допустимые токены
  },
  "start": "x07y05N",        // id стартового узла
  "win": "WIN",
  "nodes": {
    "x07y05N": {
      "cell": [7, 5],         // [x, y], x — столбец, y — строка (вверх = -y)
      "angle": "N",           // N|E|S|W
      "zone": "main",         // main|feature|hotfix|refactor|gate|arena
      "kind": "normal",       // normal|arena|win
      "key": 0,               // для normal
      "hp": null,             // для arena: 4..1
      "moves": {              // цель перехода или null, если хода нет
        "F": "x07y04N", "B": null, "L": "x07y05W", "R": "x07y05E",
        "X": "x07y05N"        // self-loop вне арены допустим
      }
    },
    "WIN": { "kind": "win", "moves": {} }
  }
}
```

Спидран-маршрут — строка токенов без разделителей, например `FFRRFXFFLXF`.
Валидатор применяет токены от `start`; попадание в `null`/несуществующий
узел/недопустимый токен = маршрут отклонён; время = количество токенов
(кликов).

## Зоны карты (ветки репозитория)

Зона кодируется символом клетки в `level/map.txt`:

| Символ | Зона | Что это |
|---|---|---|
| `.` | `main` | коридоры main |
| `f` | `feature` | крыло feature/dark-mode |
| `h` | `hotfix` | крыло hotfix/payroll |
| `r` | `refactor` | крыло refactor/auth |
| `k` | `keyroom` | комната с 🔑 LGTM |
| `g` | `gate` | коридор мерж-гейта |
| `A` | `arena` | арена прода |
| `@` | `main` | спавн игрока |
| `#` `%` `!` `~` | — | стены: код / логи / warning / конфликты |
| `G` | — | клетка мерж-гейта (проходима ⇔ key=1) |

Декоративные спрайты (замороженные баги) — символы на клетках пола в
`map.txt`: `n` = NullPointer (красный), `g` = Segfault... — фиксируются в
`level.py`.

## Бюджет

~430 проходимых клеток × 4 угла × 2 (ключ) ≈ 3440 узлов + арена
(~22 × 4 × 4 hp) ≈ 350 + меню/победа ≈ **~3800 узлов, ~3800 WebP**,
цель ≤ 250 МБ. Разрешение кадра 960×600 (рендер 320×200 ×3 nearest).

## Почему это может то, чего не может DoomMe

1. Ключ реально открывает гейт (виден в кадре: закрыт → открыт).
2. Босс реально убиваем (HP-бар, страдания в кадре, WIN-экран).
3. Спидран-лидерборд через Issues: маршрут = строка токенов, GitHub Action
   валидирует его по `data/graph.json` и обновляет `LEADERBOARD.md`.
4. Ноль сторонних ассетов — всё сгенерировано кодом этого репо.
