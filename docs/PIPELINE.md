# Как это собирается (pipeline)

Полный цикл: **уровень → граф состояний → кадры → репозиторий**.

```
level/map.txt ──► level.py ──► graph.py ──► build.py (Pool N воркеров)
                                 │                │
                                 │                ├─► render.py  ──► assets/*.webp
                                 │                └─► emit.py    ──► game/*.md
                                 │                               ├─► data/graph.json
                                 │                               ├─► README.md, LEADERBOARD.md
                                 └─► validate() (инварианты, BFS) └► _preview/*.html
```

## Шаг за шагом

1. **`level/map.txt`** — рука автора: ASCII-карта 39×26. Каждый символ пола
   кодирует зону (ветку), стены — `#` (текстура назначается по соседним
   зонам), `G` — мерж-гейт, `K` — ключ, `M` — якорь босса, `n/u/v/w/p` —
   замороженные баги-декорации.
2. **`graph.py: build_graph`** — BFS от спавна строит только достижимые
   состояния: обычные `(клетка, угол, ключ)` ×4 угла ×2 ключа, аренные
   `(клетка, угол, hp)`. Стены и запертый гейт = `None` в moves.
   `validate()` проверяет: все ссылки ведут на существующие узлы, WIN
   достижим, недостижимых нет, на клетке гейта нет узлов без ключа.
3. **`render.py`** — Wolfenstein-рейкастер, целиком векторизованный numpy
   по всем 480 колонкам сразу (DDA), текстуры 64×64 из `art.py`,
   billboard-спрайты с depth-тестом, туман, виньетка, сканлайны CRT.
   Апскейл ×2 nearest → 960×600, HUD поверх (миникарта, слот ключа,
   HP-бар босса, пушка `git blame`).
4. **`art.py`** — все текстуры/спрайты/баннеры рисуются кодом (PIL):
   «стены кода» с цветными строками, логи, `<<<<<<<` конфликты, гейт
   с замком (закрыт) и зелёной аркой (открыт), монолит в 4 стадиях
   разрушения. Шрифт — системный Consolas, отрисованный в текстуру
   (распространяется картинка, не шрифт).
5. **`emit.py`** — один узел = один `game/<id>.md` (скриншот + таблица
   3×3 эмодзи-ссылок + заголовок с веткой/позицией/ключом), плюс
   `data/graph.json` (контракт для CI-валидатора спидранов), README,
   LEADERBOARD.md и `_preview/` — HTML-зеркало, чтобы играть с диска
   без GitHub.

## Числа (сборка 0.1.0)

| Что | Значение |
|---|---|
| клеток проходимых | ~465 |
| узлов графа | ~4230 |
| кадров WebP 960×600 | ~4230 (~19 КБ средний) |
| объём assets/ | ~80 МБ |
| время полной сборки | минуты (8 воркеров) |

## Пересборка и варьирование

```
python build.py --limit 100        # смоук
python build.py --format png       # для отладки (без WebP)
python build.py --map my/map.txt   # свой уровень
python -m pytest                   # инварианты графа + лидерборд
```

Хочешь больше «плавности» — подними число углов с 4 до 8 в `graph.py`
(узлов станет вдвое больше) или уменьши шаг сетки на карте — но следи за
бюджетом: каждый бит состояния × узлы, каждый узел × ~19 КБ.
